This is a placeholder post so the Essays section isn't empty.

To publish your first real essay:

1. Delete this file (`_posts/2026-09-23-first-essay-placeholder.md`).
2. Add a new file named `_posts/YYYY-MM-DD-your-title.md`.
3. Give it front matter like this:

```yaml
---
title: "Your Essay Title"
category: essay
date: 2026-09-23
excerpt: "A one-sentence teaser shown on the home page and essays list."
---
```

4. Write the essay body below the `---`, in plain Markdown.
5. Commit and push. That's the whole workflow — no build step to run locally unless you want to preview first.
